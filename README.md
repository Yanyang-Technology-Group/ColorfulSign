## What is ColorfulSign?

**ColorfulSign** is a lightweight Paper plugin that brings **Bedrock-style color formatting** to your Java Edition server. Players can use the familiar `&` symbol (instead of `§`) to add colors, formatting, and **rainbow text effects** anywhere—chat, signs, item names, books, and more!

**Just drop it in your plugins folder and you're good to go** — zero configuration needed!

---

## Features

| Feature | Description |
|---------|-------------|
| **Simple & Syntax** | Use `&c` for red, `&l` for bold, just like Bedrock |
| **Rainbow Text** | Type `&r` to create flowing rainbow gradient effects |
| **Works Everywhere** | Chat, signs, item names, books, anvils, and more |
| **Lightweight** | Minimal performance impact, optimized for Paper |
| **Zero Config** | No setup required — just install and play |
| **Version Support** | Fully compatible with Paper 1.20 – 1.20.6; there might be some bugs on 1.21 and above. |

## 什么是 ColorfulSign？

**ColorfulSign** 是一款轻量级的 Paper 插件，可为你的 Java 版服务器带来 **基岩版风格的颜色格式化** 功能。玩家可以使用熟悉的 `&` 符号（而非 `§`）在聊天、告示牌、物品名称、书籍等任意位置添加颜色、格式以及 **彩虹文字效果**！

只需将插件放入你的 plugins 文件夹即可使用——无需任何配置！


---


## 功能

| 功能 | 描述 |
|---------|-------------|
| **简单易用的语法** | 使用 `&c` 表示红色，`&l` 表示粗体，与基岩版一致 |
| **彩虹文字** | 输入 `&r` 即可生成流动的彩虹渐变效果 |
| **全面支持** | 适用于聊天、告示牌、物品名称、书籍、熔炉等各类场景 |
| **轻量高效** | 对性能影响极小，专为 Paper 优化 |
| **无需配置** | 安装即用，无需任何设置 |
| **版本兼容性** | 完全兼容 Paper 1.20 至 1.20.6 版本；在 1.21 及以上版本可能存在部分问题|
